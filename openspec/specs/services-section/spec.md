## Purpose

Обеспечивает раздел «Сервисы»: каталог категорий с кнопками-ссылками из services API (`https://api.test.profcomff.com/services`) с отображением по доступности (`view`) и открытием ссылки по её типу (`inapp` — внутренний маршрут, `internal` — встроенный просмотр в iframe, `external` — внешняя вкладка браузера).

## Requirements

### Requirement: Секция «Сервисы» в навигации

Приложение SHALL отображать пункт «Сервисы» в боковой навигации (меню десктопа и мобильное бургер-меню); клик по пункту SHALL открывать каталог сервисов, а пункт SHALL подсвечиваться как текущий, пока открыт любой маршрут раздела.

#### Scenario: Переход из навигации

- **WHEN** пользователь кликает по пункту «Сервисы»
- **THEN** приложение открывает страницу каталога `/services`

#### Scenario: Подсветка активного раздела

- **WHEN** открыт маршрут `/services` или `/services/$buttonId`
- **THEN** пункт «Сервисы» отмечен как текущий в навигации

### Requirement: Каталог категорий с кнопками

Страница `/services` SHALL загружать категории через `GET /category?info=buttons`, передавая токен авторизации через опцию `auth`, и показывать их в порядке сервера с кнопками внутри каждой категории (иконка, название). Загрузка SHALL сопровождаться индикатором, пустой ответ — сообщением «Сервисы не найдены», ошибка запроса — текстом ошибки.

#### Scenario: Загрузка каталога авторизованным пользователем

- **WHEN** авторизованный пользователь открывает `/services`
- **THEN** приложение запрашивает категории с его токеном и показывает категории с кнопками

#### Scenario: Просмотр каталога без входа

- **WHEN** неавторизованный пользователь открывает `/services`
- **THEN** приложение запрашивает категории без токена и показывает общедоступные кнопки

#### Scenario: Пустой каталог

- **WHEN** API возвращает пустой список категорий (или категории без видимых кнопок)
- **THEN** приложение показывает сообщение «Сервисы не найдены»

#### Scenario: Ошибка загрузки

- **WHEN** запрос категорий завершается ошибкой
- **THEN** приложение показывает текст ошибки

### Requirement: Отображение кнопок по доступности

Кнопка с `view: active` SHALL быть кликабельной; кнопка с `view: blocked` SHALL отображаться визуально неактивной и не SHALL реагировать на клик; кнопка с `view: hidden` SHALL полностью скрываться из каталога.

#### Scenario: Активная кнопка

- **WHEN** категория содержит кнопку с `view: active`
- **THEN** она отображается и открывается по клику согласно своему типу

#### Scenario: Заблокированная кнопка

- **WHEN** категория содержит кнопку с `view: blocked`
- **THEN** она отображается неактивной и клик не выполняет переход

#### Scenario: Скрытая кнопка

- **WHEN** категория содержит кнопку с `view: hidden`
- **THEN** она не отображается в каталоге

### Requirement: Открытие кнопки по типу ссылки

Приложение SHALL открывать кнопку согласно полю `type`: `inapp` — внутренняя навигация роутером по ссылке-маршруту приложения; `internal` — переход на страницу просмотра `/services/$buttonId`, где ссылка рендерится в iframe; `external` — открытие ссылки в новой вкладке браузера.

#### Scenario: Внутренняя ссылка

- **WHEN** пользователь кликает кнопку с `type: inapp` и ссылкой-маршрутом приложения
- **THEN** роутер выполняет переход по этому маршруту внутри SPA

#### Scenario: Встроенная форма

- **WHEN** пользователь кликает кнопку с `type: internal`
- **THEN** приложение открывает `/services/$buttonId`, и страница рендерит ссылку кнопки в iframe

#### Scenario: Внешняя ссылка

- **WHEN** пользователь кликает кнопку с `type: external`
- **THEN** ссылка открывается в новой вкладке браузера

### Requirement: Страница просмотра сервиса в iframe

Страница `/services/$buttonId` SHALL загружать кнопку через `GET /service/{button_id}` (с токеном, если пользователь авторизован), показывать заголовок с хлебными крошками назад в `/services` и iframe с ссылкой кнопки на всю оставшуюся высоту контента. Если кнопка не типа `internal`, у неё нет ссылки или она не может быть встроена, страница SHALL показать сообщение с действием «Открыть в новой вкладке» вместо iframe.

#### Scenario: Просмотр встроенной формы

- **WHEN** пользователь открывает `/services/$buttonId` кнопки с `type: internal` и валидной ссылкой
- **THEN** страница показывает крошки «Главная / Сервисы / имя кнопки» и iframe со ссылкой

#### Scenario: Ссылка без iframe

- **WHEN** кнопка не `internal`, либо ссылка отсутствует или не является http(s)-URL
- **THEN** страница вместо iframe показывает сообщение и кнопку «Открыть в новой вкладке»

#### Scenario: Неизвестный сервис

- **WHEN** `GET /service/{button_id}` завершается ошибкой
- **THEN** страница показывает текст ошибки и крошки для возврата в каталог
