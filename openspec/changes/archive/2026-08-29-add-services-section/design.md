## Context

Сгенерированный клиент `src/shared/api/services/` (@hey-api/openapi-ts) уже содержит все ручки: `GET /category?info=buttons` возвращает `CategoryGet[]` с вложенными `ButtonGet[]`; `GET /service/{button_id}` — одну кнопку. У кнопки есть `type: 'inapp' | 'internal' | 'external'`, `view: 'active' | 'blocked' | 'hidden'`, `link`, `icon`, `name`. Безопасность — apiKey в заголовке `Authorization`, токен передаётся опцией `auth` (как в разделе «Прокат»). Приложение — SPA на TanStack Router с hash-историей; контент лежит внутри `AsideHeader`/`MobileHeader`.

## Goals / Non-Goals

**Goals:**

- Минимальный модуль страницы `src/pages/services/` по конвенциям существующих разделов (rental/dating).
- Корректное поведение трёх типов ссылок без изменений бэкенда и навигационного каркаса.
- Переиспользуемая логика «как открыть кнопку» (единый хелпер), чтобы каталог и страница просмотра не дублировали правила.

**Non-Goals:**

- CRUD-ручки категорий/кнопок (админка) — остаются для отдельного изменения.
- Автоподстановка токена в URL iframe — формы работают со своими сессиями.
- Проксирование iframe через приложение (обход X-Frame-Options) — только честный `<iframe>` с фолбэком.

## Decisions

1. **Пункт навигации статичный, категории — из API.** В `Layout.tsx` добавляется один пункт «Сервисы» (`/services`); категории рендерятся на странице. Альтернатива — динамические пункты из категорий — отклонена: категории приходят с сервера в произвольном количестве, aside-меню перегрузится, а-current подсветка для динамических маршрутов усложнит каркас.

2. **Запрос категорий с `auth: token`.** `view` вычисляется бэкендом по scopes сессии; без токена все кнопки с `required_scopes` придут `blocked`. Передаём токен, если он есть (паттерн rental: `auth` в опциях запроса/мутации).

3. **Единый хелпер `openServiceButton`.** Чистая функция в `src/pages/services/helpers.ts` (`(button, navigate) => void`): `inapp` → `navigate({ href: link })` (абсолютный href через hash-роутер; для типобезопасности достаточно `navigate` по href, как в `PageHeader`), `internal` → `navigate({ to: '/services/$buttonId', params })`, `external` → `window.open(link, '_blank', 'noopener')`. Кнопки каталога и страница просмотра переиспользуют её.

4. **Страница просмотра по id, а не по ссылке в query.** `/services/$buttonId` грузит кнопку ручкой `GET /service/{button_id}`: URL шарится и переживает перезагрузку, ссылка не тащится в адресной строке. Кнопки `not internal`/без валидного http(s)-URL — экран с сообщением и «Открыть в новой вкладке» (через существующий хелпер `n`/`resolveServiceAssetUrl` для валидации).

5. **Iframe на всю высоту контента.** Контейнер `flex: 1; min-height: 0` внутри flex-колонки страницы (у `Layout` контент уже `height: 100%`), `sandbox="allow-scripts allow-same-origin allow-forms allow-popups"` и `title` из имени кнопки. Фолбэк-сообщение выводится до загрузки кнопки (`isLoading`) и при невалидной ссылке — без мигания пустого iframe.

6. **Иконки через `n(icon, baseUrl)` (resolveServiceAssetUrl).** Относительные пути иконок резолвятся от baseUrl сервисного клиента; абсолютные http(s) проходят как есть; невалидные/отсутствующие — плейсхолдер-иконка из `@gravity-ui/icons`.

7. **`blocked` — неактивная кнопка без всплывающих подсказок о скоупах.** Пользователю достаточно факта недоступности; перечисление `required_scopes` раскрыто в API, но в UI не выводится (может меняться независимо).

## Risks / Trade-offs

- [Сторонние сайты с `X-Frame-Options: DENY`/CSP не встраиваются в iframe] → на странице просмотра iframe не единственный путь: крошки ведут назад, а для таких ссылок остаётся «Открыть в новой вкладке»; fail-состояние iframe не детектим (нет надёжного кросс-доменного сигнала), сообщение-фолбэк показываем только для заведомо невстраиваемых данных.
- [`inapp`-ссылки могут указывать на несуществующие маршруты] → несовпадение обрабатывается существующим `notFoundComponent` корня (пустой контент), пользователь возвращается навигацией; валидацию ссылок на клиенте не вводим.
- [Анонимный запрос возвращает `blocked` для scoped-кнопок] → документировано в спеке; после входа каталог перезапрашивается (query key включает токен через `auth` в опциях).
- [Хеш-роутер и внешние переходы `window.open`] → `noopener` обязателен, чтобы новая вкладка не получила доступ к `window.opener`.

## Migration Plan

Изменение аддитивное: новые маршруты, новый пункт меню, новый модуль страницы; существующие маршруты и каркас не меняются. Откат — удаление модуля `src/pages/services/`, пункта меню и маршрутов.
